## How to recapture prices

1. Open the official merchant URL (or app campaign screen).
2. Copy the discount text exactly as shown; if no number is printed, use the official campaign name or “announced, details TBA” only when the announcement itself says details are forthcoming.
3. Unknown price, %, deadline, or commission → `null`.
4. Drop anything expired (example already dropped: FPT Shop laptop phiếu 20–22/11).
5. Update `verified_at` to the recapture date.
